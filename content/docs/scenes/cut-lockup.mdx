## Usage

Cut Lockup paints its own background and runs 108 frames at 30fps. Every cut,
scale, push and the wipe are measured frame by frame off a reference recording;
each one is a prop with that measured value as its default.

```tsx
import { CutLockup } from "@/components/snap-cn/cut-lockup";

export const Intro = () => <CutLockup />;
```

Your logo goes in as SVG paths — paste the `d` of each `<path>` from your logo's
SVG (outline text first in Figma: _Outline stroke_ / _Flatten_). Each subpath is
drawn as its own construction line, with a dot on every anchor point.

```tsx
<CutLockup
  logo={{
    width: 120,
    height: 32,
    shapes: ["M0 0h20v32H0z", "M30 16a16 16 0 1 0 32 0a16 16 0 1 0-32 0z"],
  }}
  ink="#111111"
  night="#0a0a0a"
/>
```
