## Usage

Title Sweep paints its own card and runs 76 frames at 30fps. Timing is measured frame by frame off a reference; every word, colour and font is a prop.

```tsx
import { TitleSweep } from "@/components/snap-cn/title-sweep";

export const Beat = () => <TitleSweep />;
```
