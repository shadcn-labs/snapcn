## Usage

Spec Sweep paints its own card and runs 75 frames at 30fps. Timing is measured frame by frame off a reference; every word, colour and font is a prop.

```tsx
import { SpecSweep } from "@/components/snap-cn/spec-sweep";

export const Beat = () => <SpecSweep />;
```
