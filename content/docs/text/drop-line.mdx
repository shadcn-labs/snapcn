## Usage

Drop Line paints its own card and runs 38 frames at 30fps. Timing is measured frame by frame off a reference; every word, colour and font is a prop.

```tsx
import { DropLine } from "@/components/snap-cn/drop-line";

export const Beat = () => <DropLine />;
```
