## Usage

Six items run 139 frames at 30fps; each extra item adds 20 (`brandWheelDuration(n)`). The wheel comes to rest on the last item. Known brands get their mark, anything else its initial.

```tsx
import { BrandWheel } from "@/components/snap-cn/brand-wheel";

export const Beat = () => (
  <BrandWheel lead="launch on" items="X, YouTube, LinkedIn, Instagram, TikTok, Product Hunt" />
);
```
